# DocuLab documentation

DocuLab is designed as an all-in-one local document, PDF and image processing toolkit.

Current backend tools:
- Word → PDF
- PDF → Word (LibreOffice dependent)
- PDF merge
- PDF split
- PDF compress
- PDF rotate
- Image resize
- Image compress
- Image convert
- Image → PDF

Planned:
- OCR
- scanned PDF → searchable PDF
- batch operations
- richer PDF page operations
- authentication/database
- production deployment
